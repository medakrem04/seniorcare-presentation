Problématique
Contexte · Enjeux · Risques
  • 📈
    Vieillissement de la population : Le maintien à domicile des seniors crée un défi croissant pour les familles et le corps médical, exigeant une surveillance médicale continue.
  • ⏱️
    Méthodes traditionnelles insuffisantes : Les contrôles manuels intermittents entraînent des retards dans la détection des anomalies et une lourde charge pour les aidants.
  • ⚠️
    Risques critiques non couverts : Chutes non détectées · Troubles cardiaques sans surveillance · Absence de localisation GPS en cas d'urgence ou d'errance.
  • ❌
    Conséquence directe : Mise en danger de la sécurité et de la qualité de vie des personnes âgées.

Solution Proposée — SeniorCare AI
Système · Autonome · Complet
SeniorCare AI : Système de télésurveillance médicale intelligent et autonome, combinant un bracelet IoT, une application mobile multi-rôles et un backend cloud sécurisé.
⌚ Bracelet IoT
  • ▸ FC + SpO₂ (MAX30102)
  • ▸ Température IR (MLX90614)
  • ▸ Détection de chute (MPU6050)
  • ▸ SMS GSM autonome (SIM800L)
  • ▸ Localisation GPS (NEO-6M)
  • ▸ Affichage OLED (SSD1306)
📱 Application Mobile
  • ▸ Auth JWT multi-rôles
  • ▸ Médecin : dossiers + PDF
  • ▸ Famille : surveillance GPS
  • ▸ Géofencing 50–500 m
  • ▸ Courbes historiques
  • ▸ Journal des alertes
☁️ Cloud Supabase
  • ▸ PostgreSQL · 7 tables
  • ▸ Edge Functions serverless
  • ▸ Realtime WebSocket
  • ▸ JWT + Row-Level Security
  • ▸ Détection des anomalies
  • ▸ Sync seuils cloud→bracelet

Besoins Fonctionnels
22 User Stories · MoSCoW
  • 🔐
    Authentification JWT — Connexion sécurisée avec redirection automatique selon le rôle (médecin / famille)
  • 👥
    Gestion des patients — Création de dossiers, génération automatique du code SC-XXXX, accès famille via ce code
  • 💓
    Surveillance temps réel — BPM, SpO₂, Température, Détection de chute mis à jour automatiquement
  • 📲
    Alertes SMS géolocalisées — Envoi autonome via module GSM SIM800L avec lien Google Maps intégré
  • 🔄
    Synchronisation des seuils — Récupération dynamique depuis Supabase sans reprogrammation du firmware
  • 🩺
    Espace Médecin — Courbes historiques (24h / 7j / 30j), notes médicales confidentielles, rapport PDF exportable
  • 👨‍👩‍👧
    Espace Famille — Localisation GPS sur carte, géofencing (50–500 m), gestion des contacts d'urgence
  • 📟
    Affichage OLED local — Données biométriques, état GPS et alertes affichés directement sur le bracelet

Conclusion

  • ✅
    Application Flutter multi-rôles déployée — Interface Médecin + Interface Famille

Perspectives
Évolutions futures · Feuille de route
🤖 TinyML sur ESP32
Intégration d'algorithmes de machine learning embarqués pour une analyse prédictive des épisodes critiques directement sur le microcontrôleur, sans latence réseau.
❤️ Module ECG
Ajout d'un électrocardiogramme pour un diagnostic cardiovasculaire affiné, permettant la détection des arythmies et des anomalies cardiaques complexes.
🏥 Architecture Multi-patients
Déploiement dans des établissements de soins professionnels (EHPAD) avec gestion simultanée de plusieurs patients par une équipe médicale.
📲 Extension iOS
L'application étant développée en Flutter, la portabilité native vers iOS ne nécessite aucune refonte majeure — prête pour un déploiement multi-plateforme.
